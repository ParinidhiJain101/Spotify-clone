# Spotify-clone

A music player I built while learning JavaScript. Mimics the basic look and feel of Spotify.

## What it does
- Play and pause songs
- Click any song from the list to play it directly
- Seekbar to jump to any part of the song
- Equalizer animation while a song is playing

## How to run it
1. Clone the repo
2. Create a `songs/` folder and drop your own `.mp3` files in it
3. Update the songs array in `script.js` with your file names
4. Open `index.html` in a browser

> Audio files are not included in this repo due to copyright.

## Built with
- HTML, CSS, JavaScript
- Font Awesome for icons
- HTML5 Audio API

## What I learned
- DOM manipulation
- Event delegation (fixing Font Awesome SVG click issues)
- HTML5 Audio API
- Git & GitHub workflow
